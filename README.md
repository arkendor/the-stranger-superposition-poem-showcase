# The Stranger

This is a showcase for the poem *The Stranger*, the first superposition poem written in my format. It was created by arkendor, inspired by Thomas Hardy's *The Man He Killed* (1902).

[Read the poem](https://arkendor.github.io/the-stranger-superposition-poem-showcase/) or [view its JSON](The_Stranger_arkendor_superposition_poem.json). You can select words in any order and see how the probabilities change, or click "Sample" to get one plaintext reading obtained by collapsing all the superpositions.

The reader is adapted from the [Superposition Poetry Editor](https://github.com/arkendor/superposition-poetry). You can use that full editor to write and share your own poems!
